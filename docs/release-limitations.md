# Release limitations (current Windows x64 package)

- Python runtime: currently CPython 3.11.9 embeddable. Moving to CPython 3.13.16 requires dependency validation; `pywin32` 306 and `whispercpp` do not provide a simple Windows install path, while `comtypes`/`pyttsx3` validation remains pending. CPython 3.11.9 is retained temporarily because all required backend imports and packaged smoke paths pass; this is a security-currency trade-off, not a claim that 3.11.9 is patched.
- Windows speech transcription: `whispercpp` is not bundled. The published 0.0.17 wheel cannot be installed with pip because its package metadata reports version 0.0.0; building it locally requires git submodules plus Bazel (setup.py invokes `git submodule update` and a Bazel target). The import is lazy in `backend/services/voice_service.py`, so backend startup, handshake, and task execution are unaffected.
- Clean-machine verification was not performed in this environment. Embedded Python 3.13.16 import smoke against `src-tauri/resources/backend/main.py` passed locally (2026-10-27): `import backend.main` returned successfully using resource PYTHONPATH in the vendored runtime; ACL application may warn outside an installed user profile.
