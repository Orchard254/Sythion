- A 2x2 matrix (scratch tree outside the repo, child-process env only) proves
  the `.env` file and the `SYTHION_OLLAMA_API_KEY` env var are
  **alternatives** - either alone makes the test pass; only the complete
  absence of both fails it:
  - `.env` present, env var unset -> `8 passed`
  - `.env` present, env var dummy -> `8 passed`
  - `.env` ABSENT, env var unset -> **`1 failed, 7 passed`**
  - `.env` ABSENT, env var dummy -> `8 passed`
- The env var OVERRIDES the file, and - because the singleton is built at
  import - setting the variable **after** `import backend.core.config` has no
  effect. So the fix cannot be "set an environment variable at runtime"; it has
  to pin the attribute on the already-imported settings object.
