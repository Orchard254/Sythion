- Role: planner
- Goal (the slice that matters): Sythion's "better" includes runtime boundary
  integrity and honest durability of the event ledger (its replay/audit substrate).
  Item 008 (merged) shipped an atomic allocation path, but the lazy `CREATE TABLE

  same `DbEventLedger` raises `no such table`. The plan must fix that and pin
  the failure mode with a test.
