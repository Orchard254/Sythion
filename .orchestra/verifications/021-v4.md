## 2. The parser, read first

    def _candidate(value: Any) -> str:
        """Return the stripped string, or '' for anything that is not text."""

**Two halves:** (1) the value must be a `str`; (2) the value must be non-blank after `strip()`.
**Four branches,** in this order: (1) `response["message"]["content"]` (native Ollama `/api/chat`), (2) `response["choices"][0]["message"]["content"]` (OpenAI chat), (3) `response["choices"][0]["text"]` (OpenAI legacy), (4) `response["response"]` (legacy Ollama `/api/generate`).

The parser takes **the first candidate that yields a NON-BLANK string** - `if native:` / `if chat:` / `if legacy_choice:` are truthiness tests on the stripped value, and the final branch returns `_candidate(response.get("response"))`.

**What the parser ACTUALLY returns for a padded candidate: the TRIMMED value.** `_candidate("  OK  ")` -> `"OK"`, because `_candidate` returns `value.strip()`. The committed test pins `"OK"`, not the raw `"  OK  "`, and the measurement below confirms it.

### 4b. THE MASKING REASONING - verified against the code, not just the counts

The brief's subtlety is: *the endpoint re-strips the text itself, so a blank answer alone would still yield 502 without `.strip()`.* I verified this by direct measurement on both trees, with the same probe:

```
=== REAL (unmutated) reviewed tree ===
  HELPER  blank native content            -> ''
  ENDPOINT blank ALONE (no other branch)  -> status=502 detail='Inference returned an empty response'
  ENDPOINT blank MASKS a later 'OK'       -> status=200 detail=None preview='OK'
  ENDPOINT blank MASKS a later 'OK' (2)   -> status=200 detail=None preview='OK'
  ENDPOINT padded '  OK  '                -> status=200 preview='OK'

=== TEMP copy WITH mutation A (no .strip()) ===
  HELPER  blank native content            -> '   '
  ENDPOINT blank ALONE (no other branch)  -> status=502 detail='Inference returned an empty response'   <-- still 502
  ENDPOINT blank MASKS a later 'OK'       -> status=502 detail='Inference returned an empty response' preview=None   <-- was 200
  ENDPOINT blank MASKS a later 'OK' (2)   -> status=502 detail='Inference returned an empty response' preview=None   <-- was 200
  ENDPOINT padded '  OK  '                -> status=200 preview='OK'                                       <-- unchanged
```

**Confirmed, and the code explains why:** the endpoint re-strips at `routes.py:2264` (`if not str(text).strip():` -> 502) and at `routes.py:2272` (`str(text).strip()[:80]`), so:
- a blank answer ALONE still yields **502** with or without `.strip()` - the blank-answer assertion has **no teeth** on the strip half;
- a **padded** answer still yields 200 with `response_preview == "OK"` with or without `.strip()` - the padded endpoint assertion has **no teeth** either;
- but a blank candidate that **masks a later branch's real answer** is only correct when the parser strips: without `.strip()` the earlier branch's `"   "` is truthy, so the parser returns it and the later branch's `"OK"` is **swallowed** -> the gate answers **502** where it must answer **200**.

So the **MASKING case is the endpoint-level assertion with teeth on the strip half**, and the **helper-level blank cases** are the second, independent place where the strip half is pinned. Both fail when `.strip()` is removed. The strip half is genuinely pinned.
